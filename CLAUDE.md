# Проект 5: Интернет-магазин на Laravel с оплатой

## Цель
Портфолио-проект для Kwork, закрывающий нишу «интернет-магазин не на WordPress». Самый трудоёмкий из пяти, делать последним, переиспользуя наработки из предыдущих проектов (авторизация, роли, админка).

## Стек
- Laravel (последняя стабильная версия), PHP 8.2+
- Livewire + Tailwind (витрина), Filament (админка)
- Оплата: ЮKassa (тестовый режим) или CloudPayments
- Очереди для писем и обработки платежей
- MySQL

## Основные сущности
- Категории и товары (фото, цена, остаток, характеристики)
- Корзина (гость и авторизованный пользователь)
- Заказы и позиции заказов, статусы
- Платежи
- Пользователи и личный кабинет

## MVP (версия 1)
1. Каталог с категориями, поиском и фильтрами
2. Карточка товара
3. Корзина и оформление заказа
4. Оплата через ЮKassa (тестовый режим) с обработкой webhook
5. Личный кабинет: история заказов
6. Админка: товары, заказы, статусы, остатки
7. Email-уведомления о заказе

## Развитие (по этапам)
- Этап 2: промокоды и скидки
- Этап 3: складской учёт
- Этап 4: доставка (СДЭК или Почта России)
- Этап 5: email-рассылки, отзывы, избранное, SEO-оптимизация

## Требования для портфолио
- Живая демо-витрина, тестовая оплата работает
- README со скриншотами и описанием платёжного потока
- Тесты на корзину, расчёт суммы и обработку webhook оплаты
- Идемпотентная обработка платежей (повторный webhook не ломает заказ)

## Инструкции для Claude Code
- Начать с проработки схемы БД и потока заказа, затем витрина, затем оплата
- Деньги хранить в копейках (целые числа), не во float
- Ключи платёжной системы только через .env
- Интерфейс на русском языке
